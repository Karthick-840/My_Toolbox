PDF Operations

Runs locally on your machine. Upload PDFs, pick an operation, download the results.

About this tool

PDF documents are ubiquitous in professional settings. Tasks such as combining research papers, dissecting lengthy reports, or extracting specific page ranges are common but often time-consuming. This app simplifies these operations and runs entirely on your machine (it wraps my_toolbox.documents.pdf_tools).

Components
  • PDFAccess – list and read PDFs, write text to a new PDF, build a PDF from images (Snap to PDF).
  • PDF_Extract – extract text (whole document, page-wise, optional regex), images and tables.
  • PDF_Manipulate – merge, split, extract page ranges, remove blank pages, combine by prefix order, sort & rename, move or delete empty PDFs.
Core functionality
  • Merging & splitting – merge several PDFs into one (in tick order), or split a PDF into single pages.
  • Removing blank pages – streamline PDFs by eliminating pages with no text or images.
  • Custom page extraction – pull specific pages or ranges (e.g. 3-7, 10) into a new document.
Roadmap (not available yet)
  • Interactive PDF editing.
  • Intelligent document organization: automatically categorize and tag PDFs by content, metadata and usage.
  • Conversational PDF interaction with a language model: extract information, modify content or generate summaries from natural-language prompts.
Project status & contributions

The project is in its early stages, focused on core PDF manipulation. Contributions are welcome: improve features, add functionality or enhance this interface by forking the repository on GitHub.

Extract page range

Creates a new PDF from the chosen pages of each selected file. Use ranges like 3-7, 10, 12- (1-based).

Remove blank pages

Writes a copy of each selected PDF without its blank pages. A page is blank if it has no text (and no images, unless ticked below).

Combine by prefix order

Combines inputs named 0001_, 0002_, ... in the order you list. Use "Rename" first to add prefixes.

Sort & rename inputs

Adds 0001_-style prefixes to every file in Inputs (alphabetical order). This renames files.

Find empty PDFs

Checks every input PDF for text. Empty ones are moved to outputs/empty (or deleted).
